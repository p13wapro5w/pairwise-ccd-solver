# pairwise-ccd-solver

子弹速度调到 600 米每秒，打薄墙直接穿过去，打斜板又停在半空：碰撞只在帧末做点测试，单帧位移超过墙厚时整段跳过；扫掠体用 AABB 近似，斜板和薄壳出现隧道；子步数固定 4 步，帧率掉到 30 后步长翻倍；旋转碰撞体没有角速度扫掠，高速旋转的刀片漏判；触发器参与实体碰撞，进入触发区被当成墙；分层掩码在移动后没刷新，切层后仍和旧层碰撞；运动学平台把角色推穿墙，没有反向约束；接触法线取最近点，薄墙两侧法线相同，推出方向反；连续检测命中后没有回退到安全位置，角色卡进墙里；物理线程和渲染帧不同步，命中结果晚一帧；休眠体不参与扫掠，被高速物体撞到才唤醒；复合碰撞体的子形状顺序变化，扫掠结果不可复现；网络同步只发最终位置，高速穿透在客户端复现。physics/ccd_solver.py 是核心，tests/test_ccd_solver.py 15个红。要修的是：扫掠检测；OBB 扫掠；自适应子步；角速度扫掠；触发器隔离；动态掩码；运动学约束；双侧法线；安全回退；物理帧同步；休眠体唤醒；确定性顺序；网络扫掠同步。

## 运行

```bash
python -m pytest tests -q
```
